## Subsequence Selection UI Control
The Subsequence Selection UI Control serves a specific use case: when a user selects a base module, it dynamically adjusts 
the sub-module options based on the chosen base module.

Its primary purpose is to ensure that once a base module (such as a warehouse or material) is selected, 
the corresponding sub-module options (such as warehouse areas or material units) are automatically displayed and 
updated to align with the selected base module.

For more detailed information, refer to:
- [Subsequence Selection Union](SubsequenceSelectionUnion.md)
