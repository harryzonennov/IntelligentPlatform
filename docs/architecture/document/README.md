
# Document 

This section introduces the important concept of "Document," which is widely used in This software project.

## Overview

The Document concept represents each business transaction document. There are many kinds of business documents, 
such as Sales Contracts, Purchase Contracts, and Inbound Deliveries.

Each kind of document has standard structure. for the design of model, please refer to the following document:
- [Document Model](DocumentModelDesign.md)

## Model Design
DocumentContent, the full name is: platform.foundation.Model.DocumentContent is the Java Model class, which standards for the basic model of document.
